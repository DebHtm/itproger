LEARNING BY BUILDING

Small features.
Practical Angular experience.

A learning project exploring Angular through everyday ideas: keeping notes and finding movies. Each feature is a way to put a new concept into practice.

AngularTypeScriptRxJSCSS
01 / NOTES

A place for your ideas

Browse notes, read their details and add your own through a validated form. Shared state is managed by a service using signals.

02 / MOVIES

Find your next watch

Search titles through the OMDb API and explore movie posters and release years. Results and error messages update with signals.

A project in progress

Built to practise components, dependency injection, routing, forms and HTTP requests. Notes are stored in memory and reset when you reload the page. Movie search requires an internet connection.
